# PathNova Careers

Build PathNova, a premium AI-powered career discovery platform with a modern, startup-quality UI/UX. Include a complete user journey: homepage, authentication, onboarding, scientifically inspired multi-part career assessment (Big Five personality, RIASEC interests, aptitude: logical, numerical, verbal, spatial and abstract reasoning, values, skills, work style, motivation, emotional intelligence, learning preferences, and career goals), AI analysis, and a comprehensive personalized report explaining the user's profile, strengths, growth areas, personality, interests, aptitudes, values, learning style, communication style, leadership style, motivations, and work environment preferences. Generate explainable career recommendations with match percentages, detailed reasoning, skill-gap analysis, and a personalized education-to-career roadmap based on the user's current class or college year. Include immersive interactive Career Experience modules for 10 careers (Software Engineer, Doctor, Lawyer, Architect, Entrepreneur, Data Scientist, UX Designer, Psychologist, Pilot, and Teacher) with realistic day-in-the-life tasks, decision-based scenarios, AI feedback, required skills, education paths, salary insights, and future demand. Add a personal dashboard with saved careers, assessment history, learning roadmap, goals, progress tracking, AI recommendations, parent insights, career comparison, PDF report export, notifications, responsive design, smooth animations, accessibility, SEO, and a scalable architecture ready for future AI mentors, internships, and additional career experiences.Build PathNova as a production-ready AI-powered EdTech SaaS platform, not a static UI or demo. Use Next.js, React, TypeScript, Tailwind CSS, Supabase (PostgreSQL, Auth, Storage), and deployable architecture. Implement authentication (Google, email, phone), secure user accounts, backend APIs, database integration, admin dashboard, student dashboard, AI-powered career assessment, personalized reports, career recommendations, learning roadmaps, career experiences, PDF export, analytics, notifications, responsive design, SEO, accessibility, and clean scalable code. Ensure every form saves to the database, every assessment result is stored, and the owner has an admin panel to manage students, reports, and platform analytics. The application should be fully functional and deployment-ready, not just a UI prototype.
